
Oasis Infobyte (OIBSIP) - Data Science Internship Tasks
Welcome to my repository for the Oasis Infobyte Data Science Internship! Here you will find the source code, datasets, and visualization outputs for all completed tasks.
Task 1: Iris Flower Classification
Objective: Built a Supervised Machine Learning classification model to accurately classify Iris flower species based on sepal and petal measurements. Achieved 100% accuracy using the K-Nearest Neighbors (KNN) algorithm.
Tech Stack: Python, Pandas, NumPy, Scikit-Learn, Matplotlib, Seaborn
Outputs:
iris_classification.ipynb (Jupyter Notebook)
iris_sepal_scatter.png
iris_confusion_matrix.png
iris_petal_scatter.png

Task 2: Unemployment Analysis with Python
Objective: Analyzed the unemployment rate trends across different states in India, evaluating seasonal fluctuations and the economic impact of the COVID-19 pandemic.
Tech Stack: Python, Pandas, NumPy, Matplotlib, Seaborn
Outputs:
unemployment_analysis.ipynb (Jupyter Notebook)
top_10_unemployment_states.png
monthly_unemployment_trend.png
correlation_heatmap.png

Task 4: Email Spam Detection with Machine Learning
Objective: Developed an NLP-based classification model using TF-IDF Vectorization and Logistic Regression to accurately detect and filter spam emails/messages. Achieved 95.25% accuracy.
Tech Stack: Python, Pandas, Scikit-Learn (TF-IDF, Logistic Regression), Matplotlib, Seaborn
Outputs:
email_spam_detection.ipynb (Jupyter Notebook)
spam_confusion_matrix.png
