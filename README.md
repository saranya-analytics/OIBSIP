Oasis Infobyte Data Science Internship (OIBSIP)
Task 2: Unemployment Analysis with Python

Project Overview
This project analyzes the unemployment rate in India, highlighting trends over time, regional variations, and the economic impact of the COVID-19 pandemic using Python.

 Libraries & Tools Used
Python (v3.13.7)
Pandas & NumPy (Data Cleaning & Processing)
Matplotlib & Seaborn (Data Visualization)
VS Code (Development Environment)

 Key Insights & Outputs
Top 10 Regions/States:Identified states with the highest average unemployment rates using bar plots.
Monthly Trends:Visualized the time-series fluctuation of unemployment rates across different months.
Pre vs. Post COVID Analysis: Compared the average unemployment rates before and after March 2020 to evaluate the pandemic's impact.

Project Files
unemployment_analysis.ipynb: The main Jupyter Notebook containing the full code and analysis.
Unemployment in India.csv: The dataset used for analysis.
top_10_unemployment_states.png: Bar chart of top 10 states by unemployment rate.
monthly_unemployment_trend.png: Time-series trend graph.
correlation_heatmap.png: Correlation matrix heatmap.
